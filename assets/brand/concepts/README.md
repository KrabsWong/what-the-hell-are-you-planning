# Animated logo concepts

Open `preview.html` in a browser to compare the four concepts, switch background and pause animation.

- `01-compass.svg`: direction and exploration; 7-second needle movement, 18-second orbit.
- `02-confluence.svg`: three evidence streams converge; 6-second staggered trace.
- `03-strata.svg`: evidence, analysis, report; 6.5-second layer movement.
- `04-inquiry.svg`: question and insight; 7-second breathing motion.

Each file is standalone SVG with CSS keyframe animation, transparent background and a 128 × 128 viewBox. No scripts, external images or fonts. Shapes remain meaningful without animation. Reduced-motion preferences disable animation. Test at 24, 32 and 48 px in the preview.

These are proposals, not a replacement for `../planning.svg`. Browser playback does not establish animation support in the native GPUI SVG renderer. Native integration should reproduce the selected motion using the app animation facilities if SVG animation is unsupported.
